May be this is just a fun project but this little project will give the joy i am looking for days. The source code is published here and anybody can take the code, develop it and then can publish it to his/her own repository.

You just have to compile the source code written in C in your own machine and than just have to run the executable. Then it will at first print nothing but if you type "text filename" it will open the file in the terminal and than you can edit the file contents. After editing you have to press ctrl + o to save the file and if you press ctrl + q it will quit the program.
